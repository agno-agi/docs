---
title: Memory with MongoDB
description: "Store user memories in MongoDB by passing MongoDb as the agent's database."
---

## Code

```python mem-mongodb-memory.py
from agno.agent import Agent
from agno.db.mongo import MongoDb

# Setup MongoDb
db_url = "mongodb://mongoadmin:secret@localhost:27017"

db = MongoDb(db_url=db_url)

agent = Agent(
    db=db,
    update_memory_on_run=True,
)

agent.print_response("My name is John Doe and I like to play basketball on the weekends.")
agent.print_response("What do I do on weekends?")
```

## Usage

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="Set environment variables">
    ```bash
    export OPENAI_API_KEY=xxx
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    uv pip install -U agno openai pymongo
    ```
  </Step>

  <Step title="Run MongoDB">
    Install [Docker Desktop](https://docs.docker.com/get-started/get-docker/), then start MongoDB on port `27017`:

    ```bash
    docker run -d \
      --name local-mongo \
      -p 27017:27017 \
      -e MONGO_INITDB_ROOT_USERNAME=mongoadmin \
      -e MONGO_INITDB_ROOT_PASSWORD=secret \
      mongo
    ```
  </Step>

  <Step title="Run Example">
    <CodeGroup>
    ```bash Mac/Linux
    python mem-mongodb-memory.py
    ```

    ```bash Windows
    python mem-mongodb-memory.py
    ```
    </CodeGroup>
  </Step>
</Steps>
