---
title: Valkey for Team
sidebarTitle: Team Storage
description: Use Valkey to persist team sessions.
---

```python valkey_for_team.py
from agno.agent import Agent
from agno.db.valkey import ValkeyDb
from agno.models.openai import OpenAIResponses
from agno.team.team import Team

db = ValkeyDb(
    host="localhost",
    port=6379,
)

agent = Agent(
    name="Research Agent",
    model=OpenAIResponses(id="gpt-4o"),
    db=db,
)

team = Team(
    name="Research Team",
    model=OpenAIResponses(id="gpt-4o"),
    db=db,
    members=[agent],
)

team.print_response("Summarize the latest trends in AI agents")
```
