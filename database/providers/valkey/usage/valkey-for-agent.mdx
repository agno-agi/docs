---
title: Valkey for Agent
sidebarTitle: Agent Storage
description: Use Valkey to persist agent sessions.
---

```python valkey_for_agent.py
from agno.agent import Agent
from agno.db.valkey import ValkeyDb
from agno.models.openai import OpenAIResponses

db = ValkeyDb(
    host="localhost",
    port=6379,
)

agent = Agent(
    model=OpenAIResponses(id="gpt-4o"),
    db=db,
    add_history_to_context=True,
    num_history_runs=3,
    markdown=True,
)

agent.print_response("What is Valkey?")
agent.print_response("Tell me more about its vector search capabilities")
```
