## Contact Tools

### create_contact

Creates a new contact in HubSpot.

<ParamField body="email" type="string" required>
  The contact's email address
</ParamField>

<ParamField body="firstname" type="string">
  The contact's first name
</ParamField>

<ParamField body="lastname" type="string">
  The contact's last name
</ParamField>

<ParamField body="phone" type="string">
  The contact's phone number
</ParamField>

<ParamField body="company" type="string">
  The contact's company name
</ParamField>

<ParamField body="properties" type="object">
  Additional properties to set on the contact
</ParamField>

```python
contact = await agent.tools.create_contact(
    email="john.doe@example.com",
    firstname="John",
    lastname="Doe",
    phone="555-0123",
    company="Acme Corp",
    properties={
        "lifecyclestage": "lead",
        "lead_status": "new"
    }
)
```

### get_contact

Retrieves a contact by ID or email.

<ParamField body="contact_id" type="string">
  The HubSpot contact ID
</ParamField>

<ParamField body="email" type="string">
  The contact's email address (alternative to contact_id)
</ParamField>

<ParamField body="properties" type="array">
  List of properties to retrieve
</ParamField>

```python
# Get by ID
contact = await agent.tools.get_contact(
    contact_id="12345",
    properties=["email", "firstname", "lastname", "lifecyclestage"]
)

# Get by email
contact = await agent.tools.get_contact(
    email="john.doe@example.com"
)
```

### update_contact

Updates an existing contact.

<ParamField body="contact_id" type="string" required>
  The HubSpot contact ID
</ParamField>

<ParamField body="properties" type="object" required>
  Properties to update
</ParamField>

```python
updated = await agent.tools.update_contact(
    contact_id="12345",
    properties={
        "lifecyclestage": "customer",
        "phone": "555-0124"
    }
)
```

### search_contacts

Searches for contacts based on filters.

<ParamField body="filters" type="array" required>
  Array of filter objects
</ParamField>

<ParamField body="sorts" type="array">
  Array of sort specifications
</ParamField>

<ParamField body="properties" type="array">
  Properties to retrieve
</ParamField>

<ParamField body="limit" type="integer" default="10">
  Maximum number of results
</ParamField>

<ParamField body="after" type="string">
  Pagination cursor
</ParamField>

```python
contacts = await agent.tools.search_contacts(
    filters=[
        {
            "propertyName": "email",
            "operator": "CONTAINS",
            "value": "@example.com"
        },
        {
            "propertyName": "lifecyclestage",
            "operator": "EQ",
            "value": "lead"
        }
    ],
    sorts=[
        {
            "propertyName": "createdate",
            "direction": "DESCENDING"
        }
    ],
    properties=["email", "firstname", "lastname"],
    limit=50
)
```

#### Filter Operators

| Operator | Description | Example |
|----------|-------------|---------|
| `EQ` | Equals | `{"propertyName": "lifecyclestage", "operator": "EQ", "value": "lead"}` |
| `NEQ` | Not equals | `{"propertyName": "lifecyclestage", "operator": "NEQ", "value": "customer"}` |
| `CONTAINS` | Contains substring | `{"propertyName": "email", "operator": "CONTAINS", "value": "@gmail.com"}` |
| `GT` | Greater than | `{"propertyName": "hs_lead_status", "operator": "GT", "value": "50"}` |
| `LT` | Less than | `{"propertyName": "createdate", "operator": "LT", "value": "2024-01-01"}` |
| `IN` | In list | `{"propertyName": "lifecyclestage", "operator": "IN", "values": ["lead", "subscriber"]}` |

## Association Tools

### create_association

Creates an association between two HubSpot objects.

<ParamField body="from_object_type" type="string" required>
  Source object type (contact, company, deal)
</ParamField>

<ParamField body="from_object_id" type="string" required>
  Source object ID
</ParamField>

<ParamField body="to_object_type" type="string" required>
  Target object type
</ParamField>

<ParamField body="to_object_id" type="string" required>
  Target object ID
</ParamField>

<ParamField body="association_type" type="string" required>
  Type of association
</ParamField>

```python
# Associate contact with company
await agent.tools.create_association(
    from_object_type="contact",
    from_object_id="12345",
    to_object_type="company",
    to_object_id="67890",
    association_type="contact_to_company"
)

# Associate contact with deal
await agent.tools.create_association(
    from_object_type="contact",
    from_object_id="12345",
    to_object_type="deal",
    to_object_id="11111",
    association_type="contact_to_deal"
)
```

#### Association Types

| From → To | Association Type |
|-----------|------------------|
| Contact → Company | `contact_to_company` |
| Company → Contact | `company_to_contact` |
| Contact → Deal | `contact_to_deal` |
| Deal → Contact | `deal_to_contact` |
| Deal → Company | `deal_to_company` |
| Company → Deal | `company_to_deal` |

## Error Handling

All tools may raise the following exceptions:

<ResponseField name="HubSpotAPIError" type="exception">
  Raised when the HubSpot API returns an error
  
  - `status_code`: HTTP status code
  - `message`: Error message
  - `response`: Full error response
</ResponseField>

```python
try:
    contact = await agent.tools.create_contact(
        email="invalid-email"
    )
except HubSpotAPIError as e:
    if e.status_code == 400:
        print(f"Invalid request: {e.message}")
    elif e.status_code == 409:
        print("Contact already exists")
```

## Best Practices

### Batch Operations

When working with multiple records, use search operations with appropriate limits:

```python
# Process contacts in batches
after = None
while True:
    result = await agent.tools.search_contacts(
        filters=[{"propertyName": "lifecyclestage", "operator": "EQ", "value": "lead"}],
        limit=100,
        after=after
    )
    
    # Process batch
    for contact in result["results"]:
        # Process contact
        pass
    
    # Check for more results
    if not result.get("paging", {}).get("next"):
        break
    after = result["paging"]["next"]["after"]
```

### Property Selection

Only request properties you need to minimize payload size:

```python
# Good - specific properties
contact = await agent.tools.get_contact(
    contact_id="12345",
    properties=["email", "firstname", "lastname"]
)

# Avoid - getting all properties when not needed
contact = await agent.tools.get_contact(
    contact_id="12345"
)
```

### Rate Limiting

The integration handles rate limiting automatically, but you can help by:

1. Caching frequently accessed data
2. Using batch operations where possible
3. Implementing exponential backoff for retries
