The HubSpot integration enables agents to interact with HubSpot CRM, managing contacts, companies, deals, and more.
</Note>

## Overview

The HubSpot integration provides comprehensive access to HubSpot's CRM platform, allowing your agents to:

- **Contact Management**: Create, update, and search contacts
- **Company Management**: Manage company records and associations  
- **Deal Tracking**: Create and manage deals through the sales pipeline
- **Associations**: Link contacts, companies, and deals together
- **Search Operations**: Perform advanced searches across all object types

## Example Agent

Here's a simple agent that qualifies leads and creates deals:

```python
from agno import Agent
from agno.integrations import HubSpotIntegration

# Initialize the integration
hubspot = HubSpotIntegration(
    api_key=os.getenv("HUBSPOT_API_KEY")
)

# Create an agent with HubSpot capabilities
agent = Agent(
    name="Sales Assistant",
    instructions="""You are a sales assistant that helps qualify leads and create deals.
    When you receive information about a potential customer:
    1. Create or update their contact information
    2. If they're qualified, create a deal
    3. Associate the contact with the deal""",
    integrations=[hubspot]
)

# The agent can now use HubSpot tools
response = await agent.run(
    "John Doe from Acme Corp (john@acme.com) is interested in our Enterprise plan. 
    They have 500 employees and a budget of $50,000."
)
```
