---
title: ag infra delete
description: "Deletes the AgentOS codebase record from Agno config without removing any files."
---

Delete AgentOS codebase infra record

## Params

<ResponseField name="infra_name" type="Optional[str]" default="None">
  Name of the AgentOS codebase to delete, without the `-infra` suffix. When omitted, deletes the active infrastructure record from Agno config. This command does not delete files.
</ResponseField>
<ResponseField name="print_debug_log" type="bool">
  Print debug logs. `--debug` `-d`
</ResponseField>
