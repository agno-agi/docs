title: GcsJsonDb
description: "Store sessions, memories, metrics, knowledge, evals, and traces as JSON files in Google Cloud Storage."
---

`GcsJsonDb` is a class that implements the Db interface using Google Cloud Storage as the backend storage system. Each table is stored as a JSON file in a GCS bucket.

<Note>
`GcsJsonDb` accepts multiple records through the bulk methods but processes each record with an individual upsert. These methods do not reduce GCS read and write operations. In v2.7.4, `preserve_updated_at` is accepted but ignored, so an upsert replaces the existing timestamp.
</Note>
