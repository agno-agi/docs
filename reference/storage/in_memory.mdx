title: InMemoryDb
description: "Ephemeral in-process storage for sessions, memories, metrics, evals, and knowledge."
---

`InMemoryDb` is a class that implements the Db interface using an in-memory database. It provides lightweight, in-memory storage for Agent, Team, and Workflow sessions.

## Parameters

`InMemoryDb()` takes no parameters. Sessions, memories, metrics, eval runs, knowledge, and cultural knowledge are stored in internal lists. The instance `id` is an auto-generated UUID.
