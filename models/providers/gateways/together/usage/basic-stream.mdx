---
title: Streaming Agent
description: Stream a Together agent's response in the terminal.
---

## Code

```python basic.py
import os
from typing import Iterator  # noqa

from agno.agent import Agent, RunOutputEvent  # noqa
from agno.models.together import Together

agent = Agent(
    model=Together(id=os.environ["TOGETHER_MODEL_ID"]), markdown=True
)

# Get the response in a variable
# run_response: Iterator[RunOutputEvent] = agent.run("Share a 2 sentence horror story", stream=True)
# for chunk in run_response:
#     print(chunk.content)

# Print the response in the terminal
agent.print_response("Share a 2 sentence horror story", stream=True)
```

Set `TOGETHER_MODEL_ID` to a current chat model from the [Together serverless catalog](https://docs.together.ai/docs/serverless/models).
