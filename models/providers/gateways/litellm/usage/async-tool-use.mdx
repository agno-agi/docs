title: Async Tool Use
description: Run YFinanceTools from a LiteLLM-backed agent asynchronously with aprint_response().
---

## Code

```python tool_use.py
import asyncio

from agno.agent import Agent
from agno.models.litellm import LiteLLM
from agno.tools.yfinance import YFinanceTools

openai_agent = Agent(
    model=LiteLLM(
        id="gpt-4o",
        name="LiteLLM",
    ),
    markdown=True,
    tools=[YFinanceTools()],
)

asyncio.run(openai_agent.aprint_response("What is happening in France?"))
```
