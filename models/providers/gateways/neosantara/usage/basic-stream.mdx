title: Basic Stream
description: "Stream a Neosantara agent's response with stream=True."
---

## Code

```python basic.py
from agno.agent import Agent
from agno.models.neosantara import Neosantara

agent = Agent(model=Neosantara(id="grok-4.1-fast-non-reasoning"), markdown=True)

# Print the response in the terminal
agent.print_response("Share a 2 sentence horror story", stream=True)
```
