---
title: Async Streaming Agent
description: Stream an async CometAPI response with aprint_response and stream=True.
---

## Code

```python basic.py
import asyncio

from agno.agent import Agent
from agno.models.cometapi import CometAPI

agent = Agent(model=CometAPI(id="gpt-5.2"), markdown=True)

# Async streaming response
asyncio.run(
    agent.aprint_response(
        "Write a short poem about artificial intelligence", stream=True
    )
)
```
