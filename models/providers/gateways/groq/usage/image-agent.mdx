---
title: Image Agent
description: Send an image to a Groq vision model and stream the description.
---

Pass an `Image` to `print_response()` with the vision-capable `qwen/qwen3.6-27b` model.

## Code

```python image_agent.py
from agno.agent import Agent
from agno.media import Image
from agno.models.groq import Groq

agent = Agent(model=Groq(id="qwen/qwen3.6-27b"))

agent.print_response(
    "Tell me about this image",
    images=[
        Image(url="https://upload.wikimedia.org/wikipedia/commons/f/f2/LPU-v1-die.jpg"),
    ],
    stream=True,
)
```
