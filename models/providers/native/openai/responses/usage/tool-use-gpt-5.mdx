title: Tool Use GPT 5
description: Run a gpt-5 agent with cached YFinance tools through the OpenAI Responses API and stream the response.
---

## Code

```python tool_use_gpt_5.py
from agno.agent import Agent
from agno.models.openai import OpenAIResponses
from agno.tools.yfinance import YFinanceTools

agent = Agent(
    model=OpenAIResponses(id="gpt-5"),
    tools=[YFinanceTools(cache_results=True)],
    markdown=True,
    telemetry=False,
)

agent.print_response("What is the current price of TSLA?", stream=True)

```
