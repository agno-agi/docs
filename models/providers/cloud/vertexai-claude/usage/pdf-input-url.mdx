---
title: PDF Input URL
description: Fetch a PDF from a URL and summarize it with a Vertex AI Claude agent.
---

Vertex AI accepts only base64-encoded document sources, so fetch the PDF and pass its bytes with `File(content=...)`. `File(url=...)` sends a URL document source, which Vertex AI rejects.

## Code

```python pdf_input_url.py
import httpx

from agno.agent import Agent
from agno.media import File
from agno.models.vertexai.claude import Claude

agent = Agent(
    model=Claude(id="claude-sonnet-4@20250514"),
    markdown=True,
)

pdf_bytes = httpx.get(
    "https://agno-public.s3.amazonaws.com/recipes/ThaiRecipes.pdf"
).content

agent.print_response(
    "Summarize the contents of the attached file.",
    files=[
        File(content=pdf_bytes),
    ],
)
```
