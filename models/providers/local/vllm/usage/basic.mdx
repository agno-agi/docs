title: Basic Agent
description: Run a basic agent against a local vLLM server.
---

## Code

```python vllm_basic.py
from agno.agent import Agent
from agno.models.vllm import VLLM

agent = Agent(
    model=VLLM(id="Qwen/Qwen2.5-7B-Instruct", top_k=20, enable_thinking=False),
    markdown=True,
)

agent.print_response("Share a 2 sentence horror story")
```

<Note>
Install vLLM on a [supported platform](https://docs.vllm.ai/en/latest/getting_started/installation/) with a compatible accelerator. Keep the model server running in a separate terminal while you run the agent.
</Note>

## Usage

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="Install dependencies">
    ```bash
    uv pip install -U agno openai vllm
    ```
  </Step>

  <Step title="Start vLLM server">
    In a separate terminal with the virtual environment active, run:
    ```bash
    vllm serve Qwen/Qwen2.5-7B-Instruct \
        --enable-auto-tool-choice \
        --tool-call-parser hermes \
        --dtype float16 \
        --max-model-len 8192 \
        --gpu-memory-utilization 0.9
    ```
  </Step>

  <Step title="Set your API key">
    ```bash
    export VLLM_API_KEY=xxx
    ```
  </Step>

  <Step title="Run Agent">
    Save the code above as `vllm_basic.py`, then run:
    ```bash
    python vllm_basic.py
    ```
  </Step>
</Steps>
