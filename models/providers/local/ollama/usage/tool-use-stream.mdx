---
title: Tool Use Stream
description: "Stream an Ollama llama3.2 agent's tool-calling response as it searches the web with WebSearchTools."
---

## Code

```python tool_use.py
from agno.agent import Agent
from agno.models.ollama import Ollama
from agno.tools.websearch import WebSearchTools

agent = Agent(
    model=Ollama(id="llama3.2:latest"),
    tools=[WebSearchTools()],
    markdown=True,
)
agent.print_response("Whats happening in France?", stream=True)

```

## Usage

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="Install Ollama">

    ```bash
    uv pip install -U ddgs ollama agno
    ```

  </Step>

  <Step title="Run Agent">
    Save the code above as `tool_use.py`, then run:
    ```bash
    python tool_use.py
    ```
  </Step>
