---
title: Agent with Tools Stream
description: "Give a local LlamaCpp agent WebSearchTools and stream its response to a web-search query."
---

## Code

```python tool_use.py
"""Run `uv pip install ddgs` to install dependencies."""

from agno.agent import Agent
from agno.models.llama_cpp import LlamaCpp
from agno.tools.websearch import WebSearchTools

agent = Agent(
    model=LlamaCpp(id="ggml-org/gpt-oss-20b-GGUF"),
    tools=[WebSearchTools()],
    markdown=True,
)
agent.print_response("Whats happening in France?", stream=True)
```

## Usage

<Steps>
  <Snippet file="create-venv-step.mdx" />

  <Step title="Install LlamaCpp">
    Follow the [LlamaCpp installation guide](https://github.com/ggerganov/llama.cpp) and start the server:
    ```bash
    llama-server -hf ggml-org/gpt-oss-20b-GGUF --ctx-size 0 --jinja -ub 2048 -b 2048
    ```
  </Step>

  <Step title="Install dependencies">
    ```bash
    uv pip install -U openai ddgs agno
    ```
  </Step>

  <Step title="Run Agent">
    Save the code above as `tool_use.py`, then run:
    ```bash
    python tool_use.py
    ```
  </Step>
</Steps>
