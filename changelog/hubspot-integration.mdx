## Overview

We're excited to announce the HubSpot integration for Agno! This integration enables your agents to seamlessly interact with HubSpot CRM, providing comprehensive access to contacts, companies, deals, and more.

## Key Features

### 🤝 Contact Management
- Create, update, and search contacts
- Manage contact properties and lifecycle stages
- Bulk operations for efficient processing

### 🏢 Company Management  
- Full CRUD operations for companies
- Associate contacts with companies
- Track company properties and metrics

### 💰 Deal Management
- Create and manage deals through the pipeline
- Track deal stages and values
- Associate deals with contacts and companies

### 🔍 Advanced Search
- Powerful filtering across all object types
- Custom property support
- Pagination for large datasets

## Getting Started

```python
from agno import Agent
from agno.integrations import HubSpotIntegration

# Initialize the integration
hubspot = HubSpotIntegration(
    api_key=os.getenv("HUBSPOT_API_KEY")
)

# Create an agent with HubSpot capabilities
agent = Agent(
    name="CRM Assistant",
    instructions="You help manage customer relationships in HubSpot.",
    integrations=[hubspot]
)

# Start using HubSpot tools
response = await agent.run("Find all leads from this week")
```

## Migration Notes

If you're currently using custom HubSpot API calls, you can now replace them with the built-in tools:

**Before:**
```python
# Manual API call
response = requests.post(
    "https://api.hubapi.com/crm/v3/objects/contacts",
    headers={"Authorization": f"Bearer {token}"},
    json={"properties": {"email": "john@example.com"}}
)
```

**After:**
```python
# Using the integration
contact = await agent.tools.create_contact(
    email="john@example.com"
)
```
