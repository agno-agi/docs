**SerplyTools** enable an Agent to search Google, Google News, and Google Scholar.

## Prerequisites

The following example requires the `requests` and `openai` libraries and an API key from [Serply](https://serply.io/).

```shell
uv pip install -U requests openai
```

```shell
export SERPLY_API_KEY=***
```

## Example

The following agent will search Google for the query: "What are the latest developments in AI agents?" and share results.

```python cookbook/91_tools/serply_tools.py
from agno.agent import Agent
from agno.tools.serply import SerplyTools

agent = Agent(tools=[SerplyTools()])
agent.print_response("What are the latest developments in AI agents?", markdown=True)
```

Google web search is the only tool enabled by default. Turn on Google News or Google Scholar with the matching flag:

```python
from agno.agent import Agent
from agno.tools.serply import SerplyTools

agent = Agent(tools=[SerplyTools(search_web=False, search_scholar=True)])
agent.print_response("Find 3 recent papers on retrieval augmented generation.", markdown=True)
```

## Toolkit Params

| Parameter | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| `api_key` | `Optional[str]` | `None` | Serply API key. If not provided, uses the SERPLY_API_KEY environment variable. |
| `num_results` | `int` | `10` | Default number of results to return. |
| `timeout` | `int` | `30` | Per-request HTTP timeout in seconds. |
| `search_web` | `bool` | `True` | Enable the search_web functionality. |
| `search_news` | `bool` | `False` | Enable the search_news functionality. |
| `search_scholar` | `bool` | `False` | Enable the search_scholar functionality. |
| `all` | `bool` | `False` | Enable every search tool regardless of the individual flags. |

## Toolkit Functions

| Function | Description |
| -------- | ----------- |
| `search_web` | This function searches Google for a query. Returns the organic results with position, title, link, and description, along with related searches. |
| `search_news` | This function searches Google News for a query. Returns articles with title, link, source, and publish date. |
| `search_scholar` | This function searches Google Scholar for a query. Returns papers with title, link, authors, citation count, and a PDF link where one is available. |
