Deploy AgentOS to AWS with ECS Fargate, RDS PostgreSQL, and an Application Load Balancer. Production-grade infrastructure that runs entirely in your cloud.

## What's Included

| Component | Description |
|-----------|-------------|
| **AgentOS** | FastAPI server running your AI agents on ECS Fargate |
| **PostgreSQL** | RDS database with pgvector for embeddings |
| **Application Load Balancer** | HTTP/HTTPS ingress and health checks |
| **Secrets Manager** | Secure storage for API keys and DB credentials |
| **CloudWatch Logs** | Centralized logs for ECS tasks |

## Prerequisites

You'll need:

- [Docker Desktop](https://docs.docker.com/desktop/install/mac-install/)
- [uv](https://docs.astral.sh/uv/) (Python package manager)
- [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) configured with permissions for ECR, ECS, RDS, and ELB
- [OpenAI API key](https://platform.openai.com)

## Steps to Deploy

<Steps>
<Step title="Set up Python environment">

```bash
uv venv --python 3.12
source .venv/bin/activate
```

</Step>

<Step title="Install Agno">

```bash
uv pip install -U 'agno[infra]'
```

</Step>

<Step title="Create from template">

```bash
ag infra create --template agentos-aws --name my-agentos
cd my-agentos
```

</Step>

<Step title="Set your API key">

```bash
export OPENAI_API_KEY=sk-***
```

</Step>

<Step title="Configure AWS settings">

Edit `infra/settings.py`:

```python
infra_settings = InfraSettings(
    infra_name="my-agentos",
    aws_region="us-east-1",
    aws_subnet_ids=["subnet-xxx", "subnet-yyy"],
    image_repo="[ACCOUNT_ID].dkr.ecr.us-east-1.amazonaws.com",
    push_images=True,
)
```

<Note>
You need an ECR repository and public subnet IDs. See the full [AWS Deployment Guide](/production/aws/deployment-guide) for AWS setup steps.
</Note>

</Step>

<Step title="Create secrets files">

```bash
cp infra/secrets/prd_api_secrets.example.yml infra/secrets/prd_api_secrets.yml
cp infra/secrets/prd_db_secrets.example.yml infra/secrets/prd_db_secrets.yml
```

Edit both files with your credentials.

</Step>

<Step title="Deploy to AWS">

```bash
ag infra up prd:aws
```

This creates ECS Fargate, RDS PostgreSQL, and an Application Load Balancer.

</Step>

<Step title="Verify your endpoint">

```bash
aws elbv2 describe-load-balancers \
  --query 'LoadBalancers[?contains(LoadBalancerName, `my-agentos`)].DNSName' \
  --output text

curl http://[LOAD_BALANCER_DNS]/health
```

</Step>

<Step title="Set up HTTPS">

HTTPS is required to connect to the Control Plane. Follow the [HTTPS steps](/production/aws/deployment-guide#https) in the Deployment Guide.

</Step>

<Step title="Connect to AgentOS">

After HTTPS is configured, connect your deployment at [os.agno.com](https://os.agno.com). See [Connect Control Plane](/production/aws/deployment-guide#connect-control-plane).

</Step>

<Step title="Troubleshooting">

Common quick fixes:

- **ECR auth errors:** re-run `aws ecr get-login-password ...` and `docker login`
- **502 from ALB:** wait 2-3 minutes, then check ECS task logs
- **RDS slow provisioning:** RDS can take 5-10 minutes

For more, see [Troubleshooting](/production/aws/manage/troubleshooting).

</Step>
</Steps>
