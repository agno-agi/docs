Diagnose common deployment failures and apply targeted fixes.

| Issue | Cause | Fix |
|-------|-------|-----|
| ALB targets unhealthy | App not responding on `/health` | Check logs and health endpoint |
| Task keeps restarting | Startup failure or health check failure | Inspect CloudWatch logs for errors |
| `database is locked` | Multiple Uvicorn workers with DuckDB | Keep `--workers 1` when using Pal |
| Pal loses data | No EFS | Add EFS and mount `/data` |
| `CannotPullContainerError` | ECR auth expired | Re-run ECR login command |
