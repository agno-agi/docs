---
title: Mistral Embedder
description: "Generate 1024-dimensional embeddings with MistralEmbedder and mistral-embed."
---

`MistralEmbedder` uses `mistral-embed` by default. The model returns 1024-dimensional vectors.

```python mistral_embedder.py
from agno.knowledge.embedder.mistral import MistralEmbedder

embedder = MistralEmbedder()
embedding = embedder.get_embedding("The quick brown fox jumps over the lazy dog.")

print(embedding[:5])
print(len(embedding))
```

<Warning>
In v2.7.4, `endpoint` and `max_retries` use parameter names rejected by the current `mistralai` client. Pass a preconfigured client through `mistral_client` when you need either setting.
</Warning>
