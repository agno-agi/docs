---
title: Nebius Embedder
description: "Generate embeddings through the Nebius OpenAI-compatible API."
---

`NebiusEmbedder` defaults to `BAAI/bge-en-icl` with 1024 dimensions.

```python nebius_embedder.py
from agno.knowledge.embedder.nebius import NebiusEmbedder

embedder = NebiusEmbedder()
embedding = embedder.get_embedding(
    "The quick brown fox jumps over the lazy dog."
)

print(f"First values: {embedding[:5]}")
print(f"Dimensions: {len(embedding)}")
```

<Warning>
`NebiusEmbedder` sends text to the provider unchanged. For retrieval with `BAAI/bge-en-icl`, format queries with the task instruction and optional examples described in the model card. Passages remain unmodified.
</Warning>
