---
title: Together Embedder
description: "Generate embeddings through Together's OpenAI-compatible API."
---

`TogetherEmbedder` defaults to `togethercomputer/m2-bert-80M-32k-retrieval` with 768 dimensions. It reads `TOGETHER_API_KEY` and calls Together through the OpenAI SDK.

```python together_embedder.py
from agno.knowledge.embedder.together import TogetherEmbedder

embedder = TogetherEmbedder()
embedding = embedder.get_embedding("The quick brown fox jumps over the lazy dog.")

print(embedding[:5])
print(len(embedding))
```

## Run the Example
