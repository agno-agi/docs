---
title: "Multiple Servers with Partial Failure"
description: "Migrate the removed multi-server partial-failure example to supported MCPTools instances."
---

The v2 example used `MultiMCPTools(allow_partial_failure=True)`. Both the class and its partial-failure option were removed in Agno v3.

Use one `MCPTools` instance per server. Connect required servers normally. Handle optional server connection failures in application code, then pass only connected instances to the agent.

<Warning>
  Decide which servers are optional before suppressing a connection error. Log every skipped server so a degraded run remains visible.
</Warning>

See [Multiple MCP Servers](/tools/mcp/multiple-servers) for the supported v3 pattern.
