The current v3.0.4 Slack examples:

| Example | Description |
| --- | --- |
| [Serve an Agent in Slack](/examples/agent-os/slack/basic) | Mount one persistent Agent on the Slack interface. |
| [Confirm a Destructive Tool in Slack](/examples/agent-os/slack/hitl-confirmation) | Look up a subscription, then pause the persisted run with Approve and Deny actions before an irreversible cancellation tool executes. |
| [Return External Tool Execution to Slack](/examples/agent-os/slack/hitl-external-execution) | Pause on a Kubernetes diagnostic the Agent cannot execute. |
| [Coordinate a Compound Incident in Slack](/examples/agent-os/slack/hitl-incident-commander) | Combine user feedback, external execution, confirmation, and required user input in one persisted incident run. |
| [Collect Structured User Input in Slack](/examples/agent-os/slack/hitl-user-input) | Draft a support ticket from the conversation, then pause with a Slack form so the requester supplies the priority and owning component. |
| [Mount Multiple Slack Bots](/examples/agent-os/slack/multiple-bots) | Serve a research bot and an analysis bot from one AgentOS. |
| [Let One Slack App Address Another](/examples/agent-os/slack/peer-agents) | Use two Slack apps in one workspace for one-way delegation. |
| [Search Slack and Work with Files](/examples/agent-os/slack/slack-tools) | Combine channel history, thread expansion, workspace search, and file download/upload in one focused SlackTools Agent. |
| [Configure Slack Streaming UX](/examples/agent-os/slack/streaming-ux) | Show a streaming response with rotating loading messages, dynamic suggested prompts, and plan-mode task cards for tool calls. |
| [Serve a Support Team in Slack](/examples/agent-os/slack/team) | Route each Slack request to a technical specialist or a documentation specialist that can search current workspace discussions. |
| [Remember Slack Users Across Threads](/examples/agent-os/slack/user-memory) | Resolve a Slack member to an email-backed user ID when available, then use a MemoryManager to retain stable preferences across otherwise separate threads. |
| [Serve a Sequential Workflow in Slack](/examples/agent-os/slack/workflow) | Serve a two-step research and writing workflow in Slack with SQLite-backed history. |
