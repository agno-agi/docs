The Demo OS registers the `agno-expert` agent with one HTTP MCP toolkit:

```python
from agno.agent import Agent
from agno.tools.mcp import MCPTools

mcp_agent = Agent(
    id="agno-expert",
    name="Agno Expert",
    model=MODEL,
    db=agent_db,
    tools=[MCPTools(url="https://docs.agno.com/mcp")],
    instructions=INSTRUCTIONS,
    add_history_to_context=True,
)
```

`MCPTools` discovers the tool names and schemas exposed by the server. The Agno Expert can then call those tools when answering questions about Agno. It does not maintain a local documentation knowledge base.

## Agno v2.7.4 constructors

```python
from agno.tools.mcp import MCPTools
from agno.tools.mcp.params import StreamableHTTPClientParams

# Streamable HTTP. This is the default transport when url is set.
http_tools = MCPTools(url="https://docs.agno.com/mcp")

# Local stdio server. Include the executable and arguments in one command string.
stdio_tools = MCPTools(command="uvx mcp-server-time")

# Streamable HTTP with fixed request headers.
authenticated_tools = MCPTools(
    transport="streamable-http",
    server_params=StreamableHTTPClientParams(
        url="https://example.com/mcp",
        headers={"Authorization": "Bearer <token>"},
    ),
)
```

| Connection | Constructor fields |
|------------|--------------------|
| Streamable HTTP | `url`; optional `transport="streamable-http"` |
| SSE | `url` and `transport="sse"`; standalone SSE is deprecated in v2.7.4 |
| stdio | `command`; optional `env` |
| HTTP with fixed headers | `server_params=StreamableHTTPClientParams(...)` |
| HTTP with per-run headers | `header_provider=callable` with HTTP transport |

For standalone async code, manage the toolkit lifecycle with `async with MCPTools(...) as tools`, or call `await tools.connect()` and `await tools.close()` explicitly.
