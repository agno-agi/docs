Run the Demo OS locally:

```bash
git clone https://github.com/agno-agi/demo-os.git
cd demo-os
cp example.env .env  # Set OPENAI_API_KEY
docker compose up -d --build

# Load the Dash dataset and knowledge base
docker exec -it demo-os-api python -m agents.dash.scripts.load_data
docker exec -it demo-os-api python -m agents.dash.scripts.load_knowledge

# Seed Clinic schedules and patient records
docker exec -it demo-os-api python -m teams.clinic.scripts.seed_clinic
docker exec -it demo-os-api python -m teams.clinic.scripts.load_records
```

Open [os.agno.com](https://os.agno.com), add a local OS, and connect to `http://localhost:8000`.

## Registered components

The counts below come from the components registered in `app/main.py`. Agents used inside teams and workflows are not counted as separate top-level registrations.

| Type | Count | Registered components |
|------|-------|-----------------------|
| Agents | 10 | Agno Expert, Researcher, Builder, Operator, Media Lab, Planner, Voyager, Repo Explainer, Forum, Abacus |
| Teams | 4 | Dash, Mentor, Clinic, Newsroom |
| Workflows | 5 | Classifier, Scribe, Code Scout, Troubleshooter, AI Digest |

The service uses PostgreSQL for AgentOS persistence. Dash, Clinic, and Mentor also register knowledge bases backed by the same database configuration.

## Deploy to Railway

```bash
railway login
./scripts/railway_up.sh
```

The script provisions PostgreSQL, configures the Railway services, and deploys the application.
