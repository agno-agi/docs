Voyager places four custom tool calls behind three pause patterns:

```python
from agno.tools import tool


@tool(external_execution=True)
def check_live_fare(flight_id: str) -> str:
    ...


@tool(requires_user_input=True, user_input_fields=["passenger_name"])
def set_passenger_name(passenger_name: str = "") -> str:
    ...


@tool(requires_user_input=True, user_input_fields=["recipient_email"])
def set_recipient_email(recipient_email: str = "") -> str:
    ...


@tool(requires_confirmation=True)
def book_flight(
    flight_id: str,
    passenger_name: str,
    fare_usd: float,
    seat_preference: str = "",
) -> str:
    ...
```

| Component | Pause pattern | Source behavior |
|-----------|---------------|-----------------|
| Voyager | User feedback | `UserFeedbackTools` collects structured flight and seat choices |
| Voyager | User input | `set_passenger_name` and `set_recipient_email` request missing fields |
| Voyager | Confirmation | `book_flight` waits before creating a simulated reservation reference |
| Voyager | External execution | `check_live_fare` pauses so the client can execute the call and provide its result |
| Operator | Required approval and confirmation | `apply_change` waits before returning a simulated rollout record |
| Builder | Confirmation by tool name | Studio create, edit, delete, and publish operations require confirmation |
| Troubleshooter | Step input and output review | The workflow collects environment fields, then pauses for review of the proposed solution |

## Voyager

Voyager combines the pause requirements with three pre-hooks and two post-hooks:

```python
travel = Agent(
    id="voyager",
    name="Voyager",
    tools=[
        search_flights,
        check_live_fare,
        UserFeedbackTools(),
        set_passenger_name,
        set_recipient_email,
        book_flight,
        ResendTools(from_email=VOYAGER_FROM_EMAIL),
    ],
    pre_hooks=[
        OpenAIModerationGuardrail(),
        PIIDetectionGuardrail(),
        PromptInjectionGuardrail(),
    ],
    post_hooks=[output_guardrail, audit_log],
)
```

The default `PIIDetectionGuardrail()` rejects matching SSN, credit card, email, and phone patterns because `mask_pii` defaults to `False`. An email sent in the initial message is therefore rejected; the intended flow collects it through the paused `set_recipient_email` tool. The prompt-injection guardrail checks a fixed phrase list. Voyager's output hook replaces responses that match its configured sensitive-data regular expressions, and `audit_log` writes a line to standard output.

<Warning>
  Voyager runs `OpenAIModerationGuardrail` before its local PII detector. Input
  reaches the OpenAI moderation service before a later hook can reject matching
  PII. Reorder the hooks or remove the remote moderation hook when input must
  remain local.
</Warning>

Flight search uses Duffel when `DUFFEL_API_TOKEN` is set and falls back to sample results. `book_flight` returns a simulated reference. It does not charge a card or issue a real airline PNR. An external-execution client must execute `check_live_fare`, attach the result to the paused requirement, and continue the run.

## Operator

```python
from agno.approval.decorator import approval
from agno.tools import tool


@approval(type="required")
@tool(requires_confirmation=True)
def apply_change(resource: str, action: Action, summary: str) -> str:
    ...
```

Operator drafts a typed `ChangePlan` before calling `apply_change`. The approved function returns a simulated change record. It does not modify infrastructure.

## Builder

```python
StudioTool(
    registry=registry,
    db=agent_db,
    agents=True,
    versions=True,
    requires_confirmation_tools=[
        "create_agent",
        "edit_agent",
        "delete_agent",
        "publish_component",
    ],
)
```

Builder can list and run registry agents without the configured mutation gate. Create, edit, delete, and publish calls require confirmation. Versioning keeps edits as drafts until publication.

## Troubleshooter

```python
Step(
    name="collect_environment",
    executor=collect_environment,
    requires_user_input=True,
    user_input_schema=[
        {"name": "agno_version", "field_type": "str", "required": True},
        {"name": "python_version", "field_type": "str", "required": True},
        {"name": "os", "field_type": "str", "required": False},
        {"name": "install_method", "field_type": "str", "required": False},
        {"name": "details", "field_type": "str", "required": False},
    ],
),
Step(
    name="resolve",
    agent=resolver,
    human_review=HumanReview(
        requires_output_review=True,
        on_reject=OnReject.cancel,
    ),
),
```

The first pause collects environment data before research. The second pause reviews the resolver output. Rejecting the output cancels the workflow because the source sets `OnReject.cancel`.
