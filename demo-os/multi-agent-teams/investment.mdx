The standalone [investment-committee](https://github.com/agno-agi/investment-committee) companion registers seven agents, four teams, and one workflow with AgentOS.

```python
agent_os = AgentOS(
    name="Agentic Investment Team",
    agents=[
        market_analyst,
        financial_analyst,
        technical_analyst,
        risk_officer,
        knowledge_agent,
        memo_writer,
        committee_chair,
    ],
    teams=[coordinate_team, route_team, broadcast_team, task_team],
    workflows=[investment_workflow],
)
```

This implementation lives in its own repository. Demo OS does not define an Investment team under `teams/`.

## Agents

| Agent | Model | Tools |
|-------|-------|-------|
| **Market Analyst** | `gemini-3-flash-preview` | Exa MCP, YFinance, optional Parallel |
| **Financial Analyst** | `gemini-3-flash-preview` | YFinance |
| **Technical Analyst** | `gemini-3-flash-preview` | YFinance |
| **Risk Officer** | `gemini-3-flash-preview` | YFinance |
| **Knowledge Agent** | `gemini-3-flash-preview` | Knowledge search and read-only memo file navigation |
| **Memo Writer** | `gemini-3-flash-preview` | Read, search, list, and save memo files |
| **Committee Chair** | `gemini-3.1-pro-preview` | Knowledge search for research and prior learnings |

All seven agents include the fund mandate, risk policy, and evaluation process in their instructions. All seven also enable agentic memory.

## Resource attachment

The companion creates one research knowledge base and one learning knowledge base. Each agent receives only the resources listed here:

| Agent | Research knowledge | Shared learnings | Memo files |
|-------|--------------------|------------------|------------|
| Market Analyst | Yes | Yes | No |
| Financial Analyst | Yes | Yes | No |
| Technical Analyst | Yes | Yes | No |
| Risk Officer | Yes | Yes | No |
| Knowledge Agent | Yes | No | Read-only |
| Memo Writer | No | No | Read and write |
| Committee Chair | Yes | Yes | No |

The research knowledge uses PgVector hybrid search with `gemini-embedding-001`. Load the company and sector files before using it:

```bash
python -m app.load_knowledge
```

The learning configuration uses `namespace="global"` where it is attached. Knowledge Agent and Memo Writer do not receive the learning store. Memo Writer also does not receive the research knowledge base.

## Teams

Every team leader uses `gemini-3.1-pro-preview`.

| Team | Mode | Members | Leader resources |
|------|------|---------|------------------|
| **Investment Team - Coordinate** | `coordinate` | Six agents, excluding Committee Chair | Shared learnings |
| **Investment Team - Route** | `route` | All seven agents | No knowledge or learning store attached directly |
| **Investment Team - Broadcast** | `broadcast` | Market, Financial, Technical, and Risk | Shared learnings |
| **Investment Team - Tasks** | `tasks` | Six agents, excluding Committee Chair | Shared learnings |

Team leaders do not receive the research knowledge base directly. Members use their own attached resources when the leader delegates to them.

| Request | Team |
|---------|------|
| Open-ended evaluation | Coordinate |
| One specialist question | Route |
| Four independent analyst views | Broadcast |
| Decomposed portfolio task | Tasks |

## Investment workflow

The `investment-workflow` runs five stages:

1. Market Assessment with Market Analyst.
2. Fundamental Analysis and Technical Analysis in parallel.
3. Risk Assessment with Risk Officer.
4. Investment Memo with Memo Writer.
5. Committee Decision with Committee Chair.

The workflow excludes Knowledge Agent. Its participating agents keep their own model, knowledge, learning, and file-tool configuration.

## Context layers

| Layer | Contents | Attached to |
|-------|----------|-------------|
| Static context | Fund mandate, risk policy, evaluation process | All seven agent instruction prompts |
| Research library | Company profiles and sector analyses | Six agents, excluding Memo Writer |
| Memo archive | Past and newly written investment memos | Knowledge Agent and Memo Writer through different file permissions |

## Try it

```text
@Investment Team - Route What's AAPL's P/E ratio?
@Investment Team - Coordinate Should we invest in NVIDIA?
@Investment Team - Broadcast Full committee review: evaluate TSLA for $2M
@Investment Team - Tasks Deploy $10M across the top 5 AI stocks
@Investment Review Pipeline Run full investment review on NVIDIA
```
