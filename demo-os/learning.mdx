Mentor configures five `LearningMachine` stores:

```python
from agno.learn import (
    DecisionLogConfig,
    LearnedKnowledgeConfig,
    LearningMachine,
    LearningMode,
    SessionContextConfig,
    UserMemoryConfig,
    UserProfileConfig,
)

coach_learning = LearningMachine(
    db=agent_db,
    knowledge=coach_learnings,
    user_profile=UserProfileConfig(mode=LearningMode.ALWAYS),
    user_memory=UserMemoryConfig(mode=LearningMode.ALWAYS),
    session_context=SessionContextConfig(mode=LearningMode.ALWAYS),
    learned_knowledge=LearnedKnowledgeConfig(
        mode=LearningMode.AGENTIC,
        namespace="global",
    ),
    decision_log=DecisionLogConfig(mode=LearningMode.ALWAYS),
)
```

The Mentor and Curator agents share this `LearningMachine`. The Mentor team also receives it and sets `add_learnings_to_context=True`.

## Mentor stores

| Store | Mode | Source configuration |
|-------|------|----------------------|
| User profile | `ALWAYS` | Role, goals, and other profile details |
| User memory | `ALWAYS` | Durable user facts and preferences |
| Session context | `ALWAYS` | Current task and conversation context |
| Learned knowledge | `AGENTIC` | Reusable learning records saved when the model calls the learning tool; namespace is `global` |
| Decision log | `ALWAYS` | Decisions and their rationale |

`ALWAYS` runs the configured learning process for each completed interaction. `AGENTIC` exposes tools and leaves the write decision to the model. `add_learnings_to_context=True` makes retrieved learning data available to the model during later runs.

## Dash learned knowledge

Dash uses one learned-knowledge store for the team leader, Analyst, and Engineer:

```python
dash_learnings = create_knowledge("Dash Learnings", "dash_learnings")

dash_learning = LearningMachine(
    knowledge=dash_learnings,
    learned_knowledge=LearnedKnowledgeConfig(mode=LearningMode.AGENTIC),
)
```

Each component sets `learning=dash_learning` and `add_learnings_to_context=True`. Dash's instructions tell the specialists to search existing learnings and save useful SQL error patterns, schema details, and corrections.

The configuration provides storage and model-callable tools. Whether a run saves or reuses a learning depends on model behavior. The Demo OS does not measure accuracy or latency improvement from accumulated learnings.

## Planner memory

Planner uses `enable_agentic_memory=True` for user preferences and `search_past_sessions=True` for prior conversations. Its task list remains in session state. See [Memory](/demo-os/memory).
