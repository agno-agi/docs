Agno helps companies build, run, and manage their own agent platform. Use it to build customer-facing or internal agents. Build your agents once. Serve them in three places:

1. **Your product.** Add agents to your product using the REST API.
2. **Claude and ChatGPT.** Add your agents to AI apps like Claude and ChatGPT using the MCP server.
3. **Chat apps like Slack.** Add your agents to Slack, WhatsApp, and Telegram using Agno interfaces.

Build with the SDK. Run with AgentOS. Manage with the Control Plane.

| Product | Description |
|---------|-------------|
| **SDK** | Build agents, teams, and workflows with memory, knowledge, guardrails, and 100+ integrations. |
| **AgentOS** | Run your agent platform in production as a stateless, secure API and MCP server. |
| **Control Plane** | Monitor and manage your platform from the AgentOS UI. |
